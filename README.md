# Happy Boyfriend Day 💌

Open `index.html` to view. Replace `photo.jpg` to change the photo.

## Deploy on GitHub Pages
1. Create a new repository on GitHub (e.g. `boyfriend-day`), set it to Public.
2. Upload `index.html` and `photo.jpg` (Add file -> Upload files -> Commit).
3. Go to Settings -> Pages -> Source: "Deploy from a branch" -> Branch: `main` / `(root)` -> Save.
4. After about a minute your site is live at `https://<your-username>.github.io/boyfriend-day/`
